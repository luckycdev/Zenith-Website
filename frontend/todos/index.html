Zenith TODOs

Zenith TODOs

  • /plugins reload: commands created by plugins do not fully reload; may need to unregister them on reload.
  • Plugin API expansion: expose more engine/game events like message broadcast, bans, unbans, and anything else useful for plugins.
  • Plugin API docs: add full documentation and examples on a website.
  • Steam auth: investigate steam authentication.
  • Pot visuals: check RGB and goldness behavior.
  • Custom pot skins: investigate why they do not work in multiplayer.
  • Windows console: reduce flicker from resetting the typing line and stop random blank lines.
  • More architectures: build for additional targets and test them.
  • Server name changes: see whether changing the server name while it is running is possible.
  • Chat colors: support multiple colors in one message line.
  • Console chat colors: confirm chat colors carry through to console messages.
  • Player list name/rank: test whether player names can include rank text and whether the player list can be ordered.

Plugin TODOs

  • Plugin integration: make plugins able to talk to each other more easily, like GOICord + FinishAnnouncements, nickname support, and mutes with PrivateMessage.
  • ChatManager bad word/name checks: verify the filter works and improve strict mode so it does not false-match normal words like classroom.
  • Plugin config updates: check every config value on load so newer settings get added without deleting the file.
  • Config cleanup: simplify plugin config loading and remove the messy if/else style.
  • ChatManager join/leave: let join and leave messages optionally show the player rank prefix.
  • Player toggles: let players hide join/leave messages for themselves.
  • WelcomeMessage: make /togglewelcomemessage check both name and IP.
  • Placeholders: add shared placeholders other plugins can use, like %chatmanager_prefix%.
  • GOICord bot restart: add a command to restart the bot without restarting the whole plugin.
  • GOICord bot messages: add a toggle for relaying bot messages, with self-message filtering to avoid loops.
  • GOICord customization: expand bot customization for nicknames, colors, prefixes, and related settings.
  • GOICord console channel: add a Discord console channel, with optional command access for trusted roles.
  • GOICord status channel: keep an embed updated with the current player list.
  • GOICord edited messages: forward edited Discord messages back into GOI chat when enabled.
  • GOICord /discord: add an in-game command that returns the Discord invite link.
  • GOICord roles: optionally show selected Discord roles and maybe Discord global names if the API allows it.
  • GOICord replies: show when a Discord message is replying to another message.
  • GOICord server info: try to detect the public IP and use it in !info.
  • GOICord commands: add more Discord commands.
  • GOICord channels: make join/leave channels optional and support delayed join messages for returning players.
  • FinishAnnouncements: verify the height check.
  • FinishAnnouncements stats: save times to file and show fastest times for day, week, month, and all time.
  • Default banned words: ship a default banned-word list that can be overridden in config.

Other TODOs

  • Native app: replace the Zenith Electron GUI with a native app.
  • Pterodactyl egg: set up an egg for Zenith servers.
  • Website theme toggle: add light and dark mode switching to the Zenith website.
  • Update checkers: make sure every plugin and Zenith itself uses the newer update checker, and keep it blue.
  • Config checkers: make sure every plugin uses the newer config checker.
  • Chat edge cases: test what happens when server-side chat receives empty strings or spaces, and decide whether a per-feature toggle is better.

Future Plugins Ideas

  • Permissions manager: a plugin for managing roles, access, and plugin permissions.
  • Stats plugin: server and player analytics, including active times, playtime, completions, and recaps.
  • Teleport plugin: add teleport support.
  • Visibility controls: hide specific players with whitelist or blacklist support, plus optional mute controls.
  • Missed messages: show messages sent right before or after a player reconnects.
  • Private messages: add a /msg command for direct player-to-player chat.
  • Chained Together: a plugin idea for that game, possibly built on teleport support.
  • Custom commands: add simple server commands like /discord and /tutorial.
  • Vote kick / tempban: add community moderation options when staff are not around.
